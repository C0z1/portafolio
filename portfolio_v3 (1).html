001
ASTRA — Multimodal AI assistant for mobile
AI assistant built with a Flutter client and a Python/FastAPI backend. Combines text, voice and image input with LLM-powered responses, tool execution, reminders, calendar, notes, persistent memory and third-party services (Spotify, weather, search, maps). Voice transcription via Whisper, wake-word with automatic re-listening, file ingestion for PDF/DOCX/XLSX/images and locally encrypted storage.

SteamSense — Buy or Wait?
Machine Learning product that analyzes years of Steam price history and estimates whether it's worth buying a game now or waiting for a better deal. Web UI + API + authentication + data layer + deployment, with a prediction pipeline trained on historical data in DuckDB.

Liz — Local conversational AI with fine-tuning
Artificial intelligence project run entirely locally in Python, built on a LLaMA 3.0-based model with fine-tuning, designed to simulate a conversation with a person.
